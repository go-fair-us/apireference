Aedes Mosquito Surveillance Network - Americas Region 2023

This fictitious dataset contains mosquito trap collection data from a simulated continental surveillance network monitoring Aedes aegypti and Aedes albopictus populations. Includes species counts, geolocation, environmental variables, and pathogen detection results.
