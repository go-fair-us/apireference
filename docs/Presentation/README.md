# Presentation


## Summary 

A breif overview of the concepts presented in the slides follows:

**Standardization of Web Resources:** The slides advocate for a "Resource-Oriented Architecture" where data is accessed via stable, predictable URLs (Cool URIs) and standard HTTP methods. This replaces complex, custom query parameters with a simplified structure that treats data entities as addressable web resources.

**Adoption of the OpenAPI Specification:** A major focus is placed on using the OpenAPI (Swagger) Specification to provide interactive, machine-readable documentation. This ensures that both human developers and automated tools can understand and integrate with NIAID APIs without manual intervention.

**AI and LLM Integration:** The presentation highlights the emerging importance of making APIs "AI-ready." By implementing standards like the Model Context Protocol (MCP), the community can enable Large Language Models and AI agents to query biomedical databases directly.

**Developer Experience and Governance:** The deck emphasizes a "Design-First" approach, utilizing consistent error handling (HTTP status codes) and versioning strategies. This focus on governance is intended to reduce technical debt and provide a reliable, scalable infrastructure for the global research community.
